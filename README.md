# PC-store

E-commerce website for PC components and electronic devices (Phase 1 scaffold).

Goals:
- Scaffold frontend (Next.js + TypeScript + Tailwind CSS)
- Scaffold backend (Express + TypeScript)
- Provide basic health endpoint and runnable dev scripts

Tech stack:
- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL (planned)
- ORM: Prisma (planned)

Project structure:

PC-store/
- frontend/
- backend/
- docs/
- .gitignore
- README.md
- AGENTS.md

Quick start (from project root):

Frontend:
```
cd frontend
npm install
npm run dev
```

Backend:
```
cd backend
npm install
npm run dev
```
